# 网表人工审查

本工具在本机浏览器中审查**已导出的 v2 交付包**，展示全板连接、规格、
逻辑引脚与物理焊盘映射，并保存人工结论。它读取同一份已验证快照，
不修改 Circuit 文件、自动位号、Allegro 网表或 ERC/DRC 结果。

## 启动

```sh
design2allegro review <导出目录>
design2allegro review <导出目录> --port 8765 --no-browser
design2allegro review <导出目录> --state-dir /path/to/review-records
```

默认绑定 `127.0.0.1`，自动选择空闲端口并尝试打开浏览器。终端输出访问地址
和记录路径；按 Ctrl+C 停止服务。界面脚本、图形库及许可证均随 wheel 提供，
运行不需要 Node、CDN 或联网。

启动先执行交付包完整性和网表回读验证。v1 包、文件损坏或存在额外文件的包
会被拒绝。服务固定启动时的快照；导出目录重新构建后，应重新启动审查命令。

## 查看引脚与连接链

- 默认展示全板 pin 连接图，不绘制完整器件。每个引脚以类别符号、文字和接线圆点表示，
  显示位号、物理编号、逻辑名称和模块；点击进入原有引脚审核。
- 电阻、电容、电感、磁珠、晶体、二极管、LED、晶体管、芯片、稳压器、连接器、
  开关、跳线和测试点使用各自矢量符号；未知类别使用中性菱形。符号只表示 pin
  所属器件类别，不推断极性、内部引脚映射或开关导通状态，不合并多个 pin。
- 符号和文字位于接线点上方。NC 使用叉号，DNP 使用灰色符号及文字；审核通过
  在锚点旁显示绿色勾号，有问题显示红色感叹号，选中与追踪使用圆形光环。
  所有装饰均属于对应 pin，不产生额外审核对象。
- 两端普通网络用实线直接连接；多端网络通过带网名的共享节点连接。
  同一器件的多个同网 pin 始终分别保留。单端及筛选后不完整的网络保留网名，
  部分可见时标注可见／总端点数。跨模块网络直接参与连接拓扑。
- 同网 T 形分支、十字连接及重合线段分叉处显示实心圆点；普通拐角、异网交叉
  和虚线追踪跨越不加点。圆点不重复覆盖已有 pin／网络锚点，随布局、筛选、折叠
  和拖动更新。颜色随网络高亮或追踪变化，点击查看网络；不参与框选、拖动或审核计数。
- 电源／地默认只在 pin 文字中显示真实网名及标记，不绘制全板汇聚长线。
  从引脚详情可进入网络详情，查看全部端点或纠正显示方式。
- 在任意 pin 详情点击“从此追踪”，按同网连接高亮可达链。“仅看连接链”隐藏
  无关 pin，“返回全板”恢复全板，“清除追踪”清除起点与出口选择。
- 已装配两脚器件自动跨越到另一个非 NC pin，包括电容、二极管和开关。
  **虚线“追踪跨越”仅表示拓扑追踪，不表示导通、信号方向或器件内部短接**。
  它不会把两侧真实网络合并。全板视图也显示这些两脚器件的候选跨越关系。
- 到达多脚器件或 DNP 时默认停止。在该到达 pin 的详情中搜索、勾选一个或多个
  出口，然后点击“应用传播引脚”继续。NC 不可作为出口。选择属于具体到达 pin，
  不为整个器件推断输入输出；两脚 DNP 也允许手动继续。
- 电源／地和 NC 是停止点，不跨越其所在器件继续。把某个电源／地网的显示方式
  改为普通信号后，它按普通网络参与追踪。此操作仍不改变原始电气声明。
- 回环只展开一次；分支汇合保留全部关系。取消出口时从起点重算，从其他路径
  仍可到达的分支继续保留。追踪状态只存在当前页面，刷新后清除，不写审核记录。
- 元件列表和规格详情保持不变；定位元件时高亮它的 pin 集合。搜索、装配／审核
  筛选、隐藏、关联视图和模块折叠只影响显示，不改变底层传播计算。定位隐藏对象
  会展开相关模块并恢复显示；定位链外对象时返回全板。
- “按模块折叠”显示第一层模块的引脚数量摘要，点击展开；折叠摘要不是电气节点，
  不能据此判断模块内部导通。“恢复全部”清除筛选、隐藏和折叠并退出仅看连接链，
  保留追踪选择、人工审核和网络显示设置。
- 支持平移、缩放、独立拖动 pin 和 Shift + 拖动框选。滚轮每个非零纵向事件
  向上放大 15%（×1.15）、向下缩小 15%（×0.85），以鼠标位置为中心，倍率限制
  为 0.005～3；放大再缩小一步为原倍率的 97.75%。图上框选仅选择真实 pin，
  网络辅助节点和模块摘要不产生审核对象；列表仍可明确选择元件或网络进行批量审核。
- 布局在本地 Worker 中使用 ELK，按连通块排列 pin 符号与文字并生成直角连线。
  从追踪起点向外分层，方向只表示遍历顺序。模块以文字标识，不强制分区。
  低缩放隐藏文字，保留类别符号和接线点；高亮和选中对象保持文字可见。
- 拖动保留 pin 位置，并更新相邻连线的直角折线；不做全图避障优化，手动拖动可能
  产生重叠或交叉，可点击“重新布局”恢复。图不保证零交叉，也不表示封装几何。
- 布局期间列表、详情和缩放可用。“取消布局”保留当前画面；新的布局请求会终止
  旧计算，过期结果不会覆盖新画面。失败或超过 60 秒显示提示，保留画面供重试。

图表达实际 PCB 网络与明确区分的追踪关系，是连接审查工具，不是电路仿真器。

### 电源／地识别和显示纠正

优先级为：用户显示设置 → 网络 `electrical.role` → 有限网名规则 → 普通信号。
显式 `power` / `ground` 分别显示电源 / 地符号，其他显式角色按普通信号显示。
规则忽略大小写，对规范名及别名的最后一级完整匹配：

- 地：`GND`、`AGND`、`DGND`、`PGND`、`SGND`。
- 电源：`VCC`、`VDD`、`VDDA`、`VDDD`、`AVDD`、`DVDD`、`VBAT`、`VBUS`、
  `VIN`、`VOUT` 及其数字后缀，以及 `3V3`、`+3V3`、`5V`、`+5V`、`-12V` 等形式。

名称识别冲突时按普通信号显示；不通过名称子串、引脚类型或零电压推断。
网络详情显示识别依据，可选择“自动识别 / 普通信号 / 电源符号 / 地符号”。
选择自动识别即清除此网络的用户覆盖。

显示设置保存在当前浏览器 localStorage，按板 ID 和交付包指纹隔离，
不写入审核记录 JSON 或交付包。它受浏览器源隔离：更换服务端口或浏览器不会
沿用原源的设置；需要跨次启动复用时使用固定 `--port`。存储不可用时本次会话
仍生效，页面提示未持久化。显示纠正不修改电气声明或自动检查结果。

## 标记、批注和版本

元件、网络和引脚分别具有“待审 / 通过 / 有问题”状态及纯文本批注。
修改约 450 ms 后自动保存；批量标记只作用于明确选中的对象。
保存成功后显示修订号；失败时保留本地草稿并提供重试。

多个页面或服务同时编辑同一记录时，较旧修订会被拒绝，防止覆盖。
发生冲突可先导出 `review-unsaved-draft.json` 保存本地内容，再刷新记录重新编辑。
刷新时会要求确认丢弃尚未保存的修改；关闭带草稿的页面会提示未保存。

默认记录目录为 `$XDG_STATE_HOME/design2allegro/reviews/`，未设置时使用
`~/.local/state/design2allegro/reviews/`。其下按板 ID 哈希和交付包指纹隔离。
`--state-dir` 指定替代根目录，不能位于交付包内部。正常保存采用进程锁、
修订号检查和原子替换；工具不会把额外文件放进交付包。

“导出记录”下载 JSON。“导入记录”仅接受同板、同交付包指纹的数据，先列出
变化、状态及批注，再由用户确认替换。导入是整份替换，缺少的记录恢复为待审。
单条批注最多 20,000 字符，记录文件及请求限制约 8 MiB。
相同交付包复制到其他位置可以复用记录；重新生成后指纹变化则独立审查，
不会自动沿用旧结论。人工通过不会改变自动检查结果，也不是规则豁免。

## 测试与开发

```sh
pip install -e '.[dev]'
python -m playwright install chromium
make test
make test-ui
make verify-package
```

内核/API 测试和浏览器测试只使用临时合成电路及其导出包，不读取板级设计。
`test-ui` 覆盖 pin/net 完整性、两脚自动跨越、多脚出口、DNP／NC／电源停止点、
回环、分支汇合与取消、筛选折叠、实际绘制端点和直角折线、独立拖动、Worker
取消与失败恢复、审核保存与冲突、显示覆盖持久化及 10,000 pin 大图。
截图和耗时记录位于 `build/parser/review-ui/`。
wheel 验证在独立环境启动安装后的 `review` 命令并检查资源、API 和持久化。

图形库为 Cytoscape.js 3.34.3（MIT），布局库为 ELK.js 0.12.0（EPL-2.0）。
两者的来源、完整性信息及许可证随静态资源提供，运行不依赖 CDN、Node 或联网。
不再使用完整器件几何、libavoid WASM 或多候选精排。

开发者可通过浏览器中的 `graphMetrics` 查看布局耗时、节点／边数量、连通块数及连接圆点数量／更新耗时。
`graph-model.js` 维护纯数据拓扑与传播算法；`graph-worker.js` 返回节点位置和线路；
`graph-symbols.js` 缓存类别及状态 SVG；渲染器负责图形与交互。布局使用不可见
占位区域和固定水平端口，折线延伸到可见锚点，拖动后仍连接锚点。源数据及审核
记录格式保持不变。
