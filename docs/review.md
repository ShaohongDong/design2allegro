# 网表人工审查

Review 读取已验证的 v2 交付包，以左右表格对照真实 PCB 网络连接。
页面不生成原理图，不自动推断器件内部导通，不修改电路、网表或 ERC/DRC。

## 启动

```sh
design2allegro review <导出目录>
design2allegro review <导出目录> --port 8767 --no-browser
design2allegro review <导出目录> --state-dir /path/to/review-records
```

默认绑定 `127.0.0.1` 并尝试打开浏览器；终端显示地址及记录路径。
资源随 wheel 提供，不需要 Node、CDN 或联网。启动时验证交付包完整性及网表回读，
拒绝 v1、损坏或含额外文件的包。界面使用启动时的固定快照，重新导出后需重启服务。

## 左右连接对照

- 左侧选择元件，查看焊盘、逻辑引脚、引脚类型、网络或 NC 以及引脚审核状态。
  元件选择器支持位号、型号、引脚、网名搜索，以及功能路径、装配和元件状态筛选。
- 右侧选择网络，查看全部端点的位号、功能路径、焊盘、逻辑名称、类型、装配及审核状态。
  网络搜索包含别名、Allegro 名称和端点信息。
- 点击左侧引脚，右侧展示对应网络并高亮相同端点；点击右侧端点，左侧定位到所属元件和引脚。
  必要时清除目标表格的引脚筛选并翻页，使定位对象可见。
- 直接选择网络时保留左侧元件，清除不属于该网络的引脚高亮。选择元件时清空之前网络，
  防止误以为右侧仍对应新元件。NC 明确显示“不连接”，没有虚构网络或端点。
- 元件选择器筛选不会隐藏右侧网络的其他端点。当前定位对象不在选择器筛选结果中时，
  单独标为“当前定位（筛选外）”。同一器件多个同网物理引脚分别展示，DNP 仍保留真实网络归属。
- 两表各自支持搜索、引脚状态筛选、列排序和每页 60 行分页。显示“当前数量／总数”，
  当前数量为该表筛选后的总行数。长名称通过表格横向滚动完整查看。
- “返回上一位置”恢复两侧对象、筛选、排序、页码和滚动位置，最多保留 100 次导航；
  这些显示状态仅在当前页面存在。
- “详情”打开抽屉，查看元件规格、归一化值、库与设计来源，或网络名称、别名和电气声明。
  引脚详情提供所属元件和网络跳转。顶部“检查结果”可筛选规则、消息和证据，查看关联对象。

## 人工结论与批量标记

底部始终标明“当前审核元件／网络／引脚”和对象名称。点击引脚行审核该引脚；
点击元件或网络标题旁的“审核此元件／网络”可审核整个对象。
三类对象的“待审／通过／有问题”和批注独立保存，不自动传播结论。
顶部也分别统计三类对象的进度。

“下一待审项”按当前对象类型和对应列表顺序向后查找，并遵守筛选。
引脚以最近点击的一侧表格为范围；改变状态使当前行隐藏后仍能继续定位。
到达末尾不循环，也不自动通过当前项。当前对象在其他筛选条件之外时提示先选择列表对象。

复选框只选择引脚，不切换底部审核对象。“选择本页”只选择该侧可见页。
同一时间只能选择一侧；换侧勾选、切换对象、改变筛选或排序会清空原选择。
翻页可以继续积累该侧选择，批量按钮明确显示总数量。批量修改只作用于选中引脚，
不会修改元件、网络结论或批注。

## 保存、冲突与兼容

编辑约 450 ms 后自动保存。切换对象不会丢失尚未保存的批注；保存完成不重置当前输入。
失败保留本地草稿，可重试；多个页面或服务编辑同一记录时通过修订号拒绝旧版本覆盖。
冲突时可“导出记录”保存 `review-unsaved-draft.json`，再刷新记录重新编辑。
刷新会要求确认丢弃未保存修改，关闭有未保存修改的页面会提示。

记录默认存于 `$XDG_STATE_HOME/design2allegro/reviews/`，或
`~/.local/state/design2allegro/reviews/`，按板 ID 和交付包指纹隔离。
`--state-dir` 不得位于交付包内。正常保存使用进程锁和原子替换。

“导出记录”下载 JSON；“导入记录”只接受相同板和交付包指纹的数据，先显示变化与批注预览，
确认后整份替换，缺少项恢复待审。单条批注最多 20,000 字符，文件及请求上限约 8 MiB。

已有审核记录的对象标识、格式、状态、批注和修订机制保持兼容，无需迁移。
旧版浏览器中的图形显示设置不再读取。相同交付包复制到其他路径可复用记录；
新指纹独立审核，不自动沿用结论。人工通过不是规则豁免，也不是实际 Allegro 导入验证。

## 测试与维护

```sh
make test
make test-ui
make verify-package
```

自动测试使用合成电路，覆盖双向定位、NC/DNP、分页筛选、独立状态、下一待审项、
批量边界、保存失败与冲突、导入导出和 10,000 引脚网表。
浏览器截图保存在 `build/parser/review-ui/`。板级交付包用于额外人工检查，不成为通用测试依赖。

`tables.js` 负责检索索引、双表状态与导航；`records.js` 负责记录传输、草稿与导入导出；
`app.js` 负责初始化、审核区与详情。没有图形库、布局 Worker 或布线模块。
